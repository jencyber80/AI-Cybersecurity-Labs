# Scenario-AI Threat Assessment

**Status:** In progress

## Overview
This lab explores threat assessment across three GenAI and agentic AI deployment scenarios through a guided question-and-answer exercise.

## Learning objectives
- Identify threats relevant to each scenario.
- Prioritize risks based on likelihood and impact.
- Recommend appropriate security controls.
- Document reasoning, feedback, and lessons learned.

## Methodology
For each scenario, respond to one tutor question at a time, explain the reasoning behind threat identification and prioritization, then reflect on feedback and overlooked risks.

To be documented after completing the guided lab. No findings are claimed yet.

## Note
AI is used to guide discussion, not to substitute for the learner's own assessment. All scenario findings will be clearly distinguished from hypothetical examples.
